OTC Desk

Swap HRG ⇄ USDT / USDC

Trade HIDERING peer-to-peer through @HideringOTCBot — an escrow-backed Telegram bot. The bot, operated by HIDERING, holds the HRG in escrow while the buyer pays in stablecoin, then settles both legs. No order book, no exchange listing required.

Open @HideringOTCBot
How it works

Escrow in four steps

01

Post an offer

A seller runs /sell with the HRG amount, the asking price, and an HRG refund address. The bot generates a deposit address and holds the HRG in escrow.

02

Buyer matches

A buyer runs /buy on the order and sends the agreed USDT / USDC. The buyer pays the on-chain settlement gas.

03

Bot settles

Once both legs are confirmed, the bot releases HRG to the buyer and the stablecoin to the seller. Each leg is tracked — the attempt is recorded before sending, then its transaction ID — so that a restart does not resend it.

04

Done

Both parties get an on-chain confirmation. Leftover gas is refunded on a best-effort basis, and an unmatched order can be cancelled for a refund of the escrowed HRG, minus the network fee.

Commands

Bot commands

Send these to @HideringOTCBot directly. Run /help in the bot for the exact, up-to-date argument order — the bot always shows the current syntax.

/sell

Create a sell order: the amount of HRG, your asking price in USDT / USDC, and the HRG address to refund to if the order is cancelled. The bot returns a deposit address for your HRG escrow.

/buy

Take an open order and pay the stablecoin leg. Optionally pass an ETH address so leftover settlement gas can be sent back to you.

/cancel

Cancel an unmatched order you created. Escrowed HRG is automatically refunded to the address you provided when posting.

/help

Show the full command list with the exact current arguments, plus the live fee and minimum-trade parameters.

Design

How the desk protects you

Escrow by the operator

The seller's HRG must be deposited with the bot (and confirmed) before an order goes live, and the buyer's stablecoin is paid to a deposit address the bot controls. The bot is operated by HIDERING, which holds both legs until settlement.

Recorded settlement

Each leg is tracked (attempt recorded before sending, then its transaction ID), which protects against accidental resends after a restart.

Buyer-pays-gas

The on-chain stablecoin gas is paid by the buyer; leftover gas is sent back to the buyer's ETH address on a best-effort basis.

Refund on cancel

An order that never matches can be cancelled, returning the full escrowed HRG to the seller's refund address.

Stablecoin pairs

Trade against USDT or USDC. Pricing is set per-order by the seller — you negotiate, the bot enforces.

No listing needed

Move HRG in and out without waiting for an exchange listing. Peer-to-peer, directly inside Telegram.

Trade safely

The OTC desk is a peer-to-peer tool — always read the bot's /help output and confirm the order details before sending funds. Double-check addresses and amounts; on-chain transfers are irreversible. Only the official bot at t.me/HideringOTCBot is operated by HIDERING — beware of impersonators. HRG is an experimental asset; never trade more than you can afford to lose.
