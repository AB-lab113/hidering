Privacy Stack

Anonymity by Design

Layered privacy on top of Monero's proven cryptography, making transaction analysis computationally infeasible.

◎

Dynamic Ring Size

Ring size scales dynamically from 32 to 64 signers per transaction — 2–4× Monero's fixed 16. Makes statistical analysis exponentially harder.

ring-size: 32–64
▦

TX Padding

Each transaction's tx_extra is padded to a fixed 2500 bytes internally, removing size-based fingerprints. Network-layer relay padding is inherited from Monero (1024-byte granularity).

tx_extra: 2500B
⬡

Dandelion++ Stem

Transactions propagate through Dandelion++ stem/fluff routing (inherited from Monero) to obscure the originating node before broadcast.

Dandelion++
◈

Confidential Amounts

Transaction amounts are hidden on-chain by RingCT (Pedersen commitments), so observers cannot see how much value is being transferred.

RingCT
⟡

Stealth Addresses

Every payment is sent to a unique one-time address derived from the recipient's public keys, so observers cannot link transactions to a published address.

stealth one-time
⊛

Post-Quantum Ready

ML-DSA-65 (FIPS 204) + ML-KEM-768 (FIPS 203) signature upgrade in development via a non-destructive hard fork targeted for 2027 — liboqs already integrated. Existing history is fully preserved.

ML-DSA-65 · In Progress
