# 🚀 Guide de Déploiement - Hidering Ring Size 32

## Prérequis système

### Matériel minimum
- **CPU** : 2 cœurs (4 recommandés)
- **RAM** : 4 GB (8 GB recommandés)
- **Disque** : 50 GB d'espace libre
- **Réseau** : Connexion stable

### Logiciels requis
- Ubuntu 20.04+ / Debian 11+
- Ports ouverts : 18080 (mainnet P2P), 28080 (testnet P2P)
